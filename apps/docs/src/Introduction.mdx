## Using this catalog

- **Foundations** — each brand's colors, typography, spacing & motion tokens.
- **Components** — live examples with source; every component has a **Docs**
  tab (autodocs) and an **Accessibility** panel (a11y addon).
- **Theme toolbar** — the top-right control switches the active brand's theme:
  Biome light/dark on Biome stories, Exodus accent on Exodus stories.

## Consuming in an app

```tsx
import '@thijulio/biome-css/biome.css'; // once, at app root
import { Button, TerminalHero } from '@thijulio/biome-react';
// dark mode: document.documentElement.dataset.mode = 'dark'
```

```tsx
import '@thijulio/exodus-css/exodus.css'; // once, at app root
import { Field, Toast } from '@thijulio/exodus-react';
// accent theme: document.documentElement.dataset.theme = 'clay'
```

Packages publish to GitHub Packages under the `@thijulio` scope. Full guide:
the repo's `AGENTS.md`. Source: `thijulio/design-systems`.
